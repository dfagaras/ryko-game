# RYKO

RYKO is an original retro-space ricochet arcade game built with Godot 4.

## Current prototype

The first vertical slice includes:

- portrait mobile board;
- seven invisible placement columns;
- empty space between blocks with no visible grid;
- square and true triangular collision blocks;
- a simple arrow launcher;
- one luminous ball;
- touch and mouse aiming;
- an aim preview that stops at the first collision;
- wall and block ricochets;
- automatic ball reset.

## Download the Android build

1. Open the repository's **Actions** tab.
2. Select **Android Debug APK**.
3. Open the newest successful run from `develop`.
4. Download the `ryko-android-debug` artifact.
5. Extract the ZIP and install `ryko-debug.apk` on an Android phone.

Android may ask for permission to install an unknown app from your browser or file manager.

## Controls

Drag above the launcher to choose an angle, then release to shoot.

## Branches

- `develop`: active prototype development.
- `main`: stable releases only.
